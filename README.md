# JokerShift 🃏

Мобильная версия карточной игры на Godot 4.7.2.

## Как собрать APK

1. Скачай подготовленный архив **JokerShiftProject.zip** из чата.
2. Зайди в [загрузку файлов](https://github.com/fF0GGY824/JokerShift/upload/main).
3. Загрузи **JokerShiftProject.zip** как один файл в корень репозитория (не распаковывай) и нажми **Commit changes**.
4. Автоматически запустится [Build JokerShift APK](https://github.com/fF0GGY824/JokerShift/actions/workflows/android.yml).
5. Открой успешный запуск, скачай **JokerShift-Android-APK** из раздела **Artifacts**. В скачанном архиве будет `JokerShift.apk`.

Сборка создает тестовый APK для ARM32 и ARM64, с вертикальной ориентацией (portrait) и адаптивным интерфейсом. Реальный мультиплеер ещё в разработке.

> Проектные исходники пока поставляются одним ZIP: GitHub Actions распаковывает его автоматически перед сборкой. Этот README и workflow уже добавлены в репозиторий.

## Онлайн через Render

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/fF0GGY824/JokerShift)

Кнопка открывает развёртывание сервера в твоём Render. Нужно войти в свой Render, подтвердить подключение GitHub и запуск сервиса. Само нажатие по ссылке ничего автоматически не развёртывает.

Конфигурация `render.yaml` автоматически распаковывает архив JokerShift из корня репозитория. Сейчас используется имеющийся `JokerShiftProject для апк.zip`; если добавить `JokerShift_EASY_ONLINE_RENDER_READY.zip`, будет использоваться более новый сервер.

После запуска скопируй реальный адрес сервиса `https://<имя>.onrender.com` из Render, замени начало на `wss://` и вставь в игре в разделе «Подключение». При использовании бесплатного сервиса первый вход после простоя может быть долгим.

Пока Render не развёрнут, **рабочего публичного сервера нет**. Для постоянной истории друзей / чатов нужна отдельная долговременная база данных.
